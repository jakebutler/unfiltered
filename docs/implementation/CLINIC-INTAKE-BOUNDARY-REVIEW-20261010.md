## Smallest coherent decision

1. **One inference call returns typed proposed records and explicit conversation events.** Derive readable field meanings/types and all volunteered-topic destinations from the shared authored native content. Include the actual displayed question as separately authored context. Keep missing fields absent, explicit scoped exceptions, persons/items/periods and correction targets. Remove the source-first prose stage and its topic-hint/held-report wrapper from the selected successor; no new narrative generator or verifier.
2. **The server owns lineage.** Bind the entire accepted patient turn, its digest, patient/session/operation/content revision, timestamp/channel and transformations before dispatch. Attach that immutable source to each admitted record. Optional subspans must resolve exactly to that source before they are displayed as highlights. A missing or malformed optional span receives a diagnostic and a full-turn source view; it never becomes fabricated evidence or borrowed assistant text. Keep exact raw provider bytes/audit. Do not silently rebind old outputs or fill legacy predicate fields with invented full-turn predicates.
3. **Validate semantic units provisionally.** Check issued field/item identity, native type/state rules, permitted subject, dates/units, duplicate/conflict/correction scope and known unsafe inference cases. A local record failure becomes an explicit unresolved detail; unrelated admissible records remain available in the same draft. Linked identity/attribute/correction records form a dependent unit: rejected identity or parent holds its children. Conflicting alternatives remain unresolved rather than choosing a winner. Valid lineage or an optional quote alone grants no semantic correctness.
4. **Keep one atomic candidate and CAS.** Stage accepted records plus gaps together. Recompute the shared authored native projection against the current trusted qualification and exact content version; admit dependent facts only after their required parent is valid in that same candidate. Rejected parents retain children as unresolved source context. Save records, gaps, operation outcome and next question together once. Keep source identity checks, stale target generations, cancellation/deadline/receipt handling and post-commit reconciliation ([session:278–317,477–485](/Volumes/rexy/GitHub/codex-worktrees/unfiltered-foundation/unfiltered/packages/clinic-api/src/adaptive-extraction-grouped-session-v2.ts:278)). Whole-envelope atomicity stays; all-or-nothing semantic validity can change.
5. **Scope the effect of a gap.** A gap cannot answer a minimum, close a list, activate its branch, stop a topic or grant readiness. The existing native planner may ask an independent safe prompt or an authored clarification while naming the unresolved detail. It must not mark the whole source accounted for or skip an uncertain affected topic. Envelope misbinding, unknown execution, stale context and invalid persistence still withhold authoritative advancement. Invalid optional annotation alone can be nonblocking because the server-bound source remains intact.
6. **Retain final fact plus full-source review and human handoff.** Rejected interpretations stay out of confirmed facts; unresolved patient wording can accompany an explicitly partial handoff. Change final eligibility only at the independently admissible fact/dependency boundary, retaining exact fact/source/version digests and full source inventory. No source receives wholesale credit because one sibling fact passed. Patient review is necessary, and it cannot replace independent semantic evaluation ([DELIVERY-ACCEPTANCE:23](/Volumes/rexy/GitHub/codex-worktrees/unfiltered-foundation/unfiltered/docs/implementation/DELIVERY-ACCEPTANCE.md:23)).

This is a successor provenance/validation profile. Existing predicate-based lexical ownership/uncertainty checks consume selected text ([provisional-draft.ts:112–150](/Volumes/rexy/GitHub/codex-worktrees/unfiltered-foundation/unfiltered/packages/clinic-api/src/provisional-draft.ts:112)); feeding them the whole turn would incorrectly let a mother's condition or uncertainty about one medicine affect unrelated patient facts. Migrate those consumers deliberately to record scope and verified optional context, retaining unresolved handling where ownership or meaning cannot be established. Do not turn off semantic checks globally.

## Migration and acceptance boundary

One implementation batch should cover four existing seams: provider contract/typed adapter; provisional record admission and dependency merge; handler settlement/native planning; final review/confirmed-source eligibility. Reuse the actual handler, saved-draft/resume path, native questionnaire, FHIR delivery and staff views. Preserve the qualified native Questionnaire/version/enableWhen behavior, PHQ path, auth, provider accounting and Medplum transaction boundary. New extraction/representation profile receipts must be qualified separately; old receipts cannot qualify changed semantics. No new database, router, generic workflow engine or agent framework is needed. Historical codecs/evidence can remain for replay; retire their runtime selection after the successor is accepted.

Subsequently, only separately authorized qualification can assess precision, volunteered-detail recall and the untouched qualification set. Measure complete usable text/audio latency, save/resume parity and failures on the selected artifact; the five-second p95 target remains unchanged. Removing one serial call is an architectural reduction, not a demonstrated performance result. Current activation stays disabled, and no additional probe is authorized by this report.
